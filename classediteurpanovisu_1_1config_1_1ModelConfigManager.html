ModelConfig editeurpanovisu.config.ModelConfigManager.chargeCatalogue ( String  chemin,
String  libelle,
Supplier< ModelConfig >  repli 
)
private

Charge un catalogue de modèles, en trois temps.

D'abord le fichier de configPV/, que l'utilisateur peut modifier. S'il est absent ou vide, le catalogue embarqué dans le JAR prend le relais, puis est recopié dans configPV/ pour rester modifiable.

Ce repli est indispensable : le répertoire configPV est exclu de l'installeur (il peut contenir des clés) et n'existe donc pas au premier lancement. Sans lui, la liste de modèles était vide chez tout utilisateur installé.

Paramètres
cheminChemin relatif du catalogue, aussi utilisé comme nom de ressource
libelleNom du fournisseur, pour les messages
repliConfiguration minimale si même la ressource embarquée manque
Renvoie
Une configuration jamais nulle
